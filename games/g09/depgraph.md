依赖为三条支线汇入终局：
1. 端详绣绷 → 花带次序（说亲→定亲→过礼→迎娶→回门）＋样品架蝶数 → 转牌锁 2-1-4-3-5 → 箱开 → 模芯版
2. 端详绣绷 → 线轴篮 → 卡销
3. 端详鼎罐 → 压条
4. 三件齐 → 母模装回压模架 → 压片（win）

环检查：所有边单向（线索／物品 → 动作 → 新标志／新物品），标志只增不减，箱锁→模芯版→拼装为单向链——无环，通过。

依赖为四条支线汇入终局：
1. 读投料记录簿 → 封窖配比页（批次×斤两配比表）
2. 端详吊秤 → 三次两两称量（乙＞甲＞丙）＋配比档位 → 记下斤两（丙=3/甲=5/乙=7）
3. 配比＋称砣＋挂钩錾字 → 按序挂砣（丙→甲→乙，标志链硬锁序）→ 窖门开
4. 记账板 → 酒提；端详挂钩（黑得深）→ 马灯＋火柴 → 点灯；进窖 → 端详铜牌＋记录簿桶号 → 十二号桶 → 启封（win）

环检查：所有边单向（线索／物品 → 动作 → 新标志／新物品），标志只增不减；配比页→称砣档位→挂砣为单向链，挂砣 g1→g2→g3 为标志链硬序——无环，通过。

# g23 · 压轴出场之前（种子 s23：环球巡演的巨型马戏帐篷）

## 一、设定

环球巡演第七十三站，散场后的午夜。你是新来的道具学徒，团长临睡前交代了一件事：明早开演前，四只道具箱必须按出场顺序挂上中央吊架，配重筐配平——圆场暗门下的地下库房里，锁着明早要提的巡演总账和空中飞人的备用保险绳，那扇暗门只认吊架的分量。

麻烦在于，节目单被大风撕散，四页纸散落在服装间的针线筐边；绞盘师傅跟巡演队回了老家，只在绞盘棚里留下一块排程板和几条口口相传的规矩；团长把校秤的标准砝码锁进了办公桌，钥匙却挂在马厩的钉板上。更糟的是，配重筐里那四块铁的漆字全被磨平了，台秤还被人动过手脚——上一位学徒走前没校秤。

暗门锁链穿过两只滑轮吊着配重筐：吊架两侧的分量差一公斤，差动锁就咬死不放。你要理顺出场单、按序挂箱、校秤称铁、配平配重，在天亮检场铃响之前把地下库房打开。

## 三、机制对应说明

- **时序 → 出场排程（规则锁定）＋道具箱加载（标志链硬锁）**：出场顺序由三条互斥规则排除锁定——散页"空中飞人永远压轴"、日程板"彩球箱与礼帽箱必须一前一后中间不插箱"、喂食表背字"铃鼓箱头一个上，彩球箱跟在后面"。若彩球排第三，礼帽将挤进压轴位与飞人冲突，唯一解：铃鼓→彩球→礼帽→扣件。挂箱动作被标志链硬性锁序（彩球→礼帽→扣件），抢先挂别的箱只咬不上横梁；乱序时序错误只会得到失败文案，不推进流程。
- **重量或平衡 → 吊秤校验＋称铁＋配平（三段推理）**：先以 1kg 标准砝码校出台秤虚高 2kg 的偏差；再称漆字磨平的配重铁（读数 22/3，扣偏差得实际 20kg 与 1kg 各两块）；最后按道具箱标签净重合计 42kg（12+9+15+6），推出配重筐需 20+20+1+1 的组合才能使差动滑轮两侧平衡。称量、偏差修正、配平三层推理缺一不可；只挂两块 20kg 的错误组合会让指针甩进红区。

## 四、结局方向

- **win（把总账和保险绳提上圆场）**：库房铁架码得整齐，玻璃柜里锁着巡演总账——总账与飞人备用保险绳被提上圆场，明早开演前团长的交代一件不差。
- **lose（隔着栏杆逗弄美洲豹，全关唯一败局）**：豹爪从栏杆缝里拍出来，爪尖擦过手背——驯兽员的哨子还挂在墙钩上，可值夜的帐篷里再没有第二个人。

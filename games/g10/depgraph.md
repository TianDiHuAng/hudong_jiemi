依赖为四条支线汇入终局：
1. 检修间扳手 → 三台机器端详＋读日志（对话推理证词链）
2. 备件架三单据交叉排除（裂纹→压碎／集尘盒→翻新／编号最大→外运）→ 扫地机取蓄电池
3. 三段日志＋规程牌 → 扳 E-12 拉杆 → 笼开 → 权限卡
4. 蓄电池装仓 → 口令 21（真话者 E-12 编号倒写）→ 复位 → 权限卡过闸（win）

环检查：所有边单向（线索／物品 → 动作 → 新标志／新物品），标志只增不减；日志→拉杆→取卡→过闸为单向链，电池→复位为单向链——无环，通过。

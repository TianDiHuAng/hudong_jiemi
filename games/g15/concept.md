# g15 · 缺角的纪年（种子 s15：沙暴将至的沙漠考古营地，难度 hard）

## 一、设定

沙暴橙色预警在营地电台里循环，老队长的规矩写在工作帐的值班笔记上：封存走完之前，谁也不许撤。保险柜里躺着 M7 新出土的四方墓志拓片，柜码是老队长留下的谜——"三针取生、卒、厝，各按日晷刻度再减三"。可 M7 的纪年偏偏残了：出土记录卡上只写明"生以卯、厝以戌"，卒期那一角，在校样上缺得整整齐齐。

筛场里还埋着答案的碎屑。技术员跑场时吹丢了校样的纪年角，三枚碎角混在筛余的沙堆里，颜色茬口各不相同：乌墨的带着青石细茬，灰淡的是麻石粗茬，朱砂的是砖茬。工作帐的登记簿记得明白——M7 青石乌墨，M2 麻石墨淡，M5 红砂土黄，M9 砖志朱砂。认色、拼角、读出"卒以午"，再去日晷盘上把卯、午、戌换成刻度、各减去三，保险柜才会开。

柜开后还要抢时间：M7 拓片装进密封抢救筒，登记签填上编号，人抱着筒钻进吉普——沙墙已经立起来了。

## 三、机制对应说明

- **密码替换 → 保险柜**：密码经三级合成，不以明文出现——第一级，生、卒、厝三个地支（卯／午／戌）分别来自出土记录卡与排除法补全的校样残角；第二级，日晷盘给出"支→刻度"映射（卯4、午7、戌11）；第三级，值班笔记规则"各按刻度再减三"得 1、4、8。直读 478、倒序 841、凑数 147 三组错答各有独立反馈。
- **逻辑推理 → 缺角补全**：三枚碎角互斥，登记簿给出唯一可判定的排除依据（M2 麻石墨淡、M5 红砂土黄、M9 砖志朱砂、M7 青石乌墨），逐一排除后仅剩乌墨青石一枚为真解；拼错的两枚错答从纸色与茬口两个维度给出反驳，锁定唯一解。

## 四、结局方向

- **win（抱抢救筒上车撤离）**：吉普点火扎进风里，后视镜里的营地被沙墙吞没，怀里的抢救筒贴着背心还是凉的。
- **lose（抄近路翻东沙梁）**：沙墙比脚程快，梁顶风立起来，来路被抹成昏黄——全关唯一败局，动作明确危险。
